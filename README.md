# HEIMDALL

HEIMDALL은 웹·API·모바일 앱의 테스트와 원격 기기 제어를 한곳에서 다루는 독립적인 오픈소스 프로젝트예요. 브라우저에서 테스트 시나리오를 작성하고, 실행 과정을 확인하며, 결과와 증적을 살펴볼 수 있어요.

## 주요 기능

- **프로젝트별 테스트 관리**: 시나리오·테스트데이터·실행 기록을 프로젝트 단위로 관리해요.
- **시나리오 실행**: 저장한 동작에 입력값과 기대 결과를 연결하고, 단계별 진행과 결과를 확인해요.
- **AI 테스트 지원**: 테스트 목표를 전달하고 실행 과정에서 관찰·조작·검증을 진행해요.
- **원격 기기 제어**: Android와 iOS 기기 화면을 보고 조작하며, 기기의 연결·점유 상태를 확인해요.
- **웹 디버깅**: Android WebView·Chrome과 iOS Safari·검사 가능한 WKWebView에 연결해요.
- **결과 확인**: 실행 기록·스크린샷·콘솔과 검증 결과를 통해 동작을 추적해요.
- **도구 연동**: MCP를 통해 외부 도구에서 테스트 기능을 사용할 수 있어요.

## 사용 흐름

1. 프로젝트를 만들고 앱·웹·API 중 테스트할 유형을 선택해요.
2. 테스트 대상과 동작·검증 조건을 시나리오로 저장해요.
3. 필요한 경우 테스트데이터를 입력값·기대 문구·API 상태·주소에 연결해요.
4. 시나리오를 실행하고 진행 단계와 결과를 확인해요.

실행할 때 적용한 동작과 데이터 정보는 새 실행 기록에 남고, 원본 시나리오는 유지돼요. 검증 조건 통과, 검증 없는 동작 완료, 실패, 중단을 구분해요.

## 플랫폼별 기능

| 대상 | 기능과 조건 |
| --- | --- |
| 웹 | Playwright 기반 브라우저 관찰·조작·시나리오 실행 |
| API | 요청 실행과 기대 상태 등 검증 조건 확인 |
| Android | 원격 조작·앱 설치·WebView 디버깅. 에뮬레이터에서는 지원되는 휴대폰 설정을 변경할 수 있어요. |
| iOS | 기기 에이전트를 통한 원격 연결과 웹 디버깅. 카메라 설정·휴대폰 설정·앱 설치 패널은 제공하지 않아요. |

웹 디버깅은 대상 앱이나 브라우저에서 검사를 허용해야 사용할 수 있어요. 기기 종류와 연결 도구에 따라 지원 범위가 달라져요. 에이전트 연결 방법은 [기기 에이전트 안내](device-agent/README.md)를 참고해 주세요.

## 소스 구조

| 경로 | 역할 |
| --- | --- |
| `studio/` | React·TypeScript·shadcn/ui 기반 웹 화면 |
| `server/` | Node.js API·테스트 실행·인증·실시간 연결 |
| `browser-worker/` | Playwright 브라우저 실행기 |
| `device-agent/` | macOS 기기 에이전트 |
| `contracts/` | 화면·서버·워커가 공유하는 API 타입 |
| `web/studio/` | 웹 화면 빌드 산출물 |

실행 기록은 PostgreSQL에 저장하며, 화면과 서버는 HTTP·WebSocket으로 통신해요.

## 공개 자료 원칙

예제에는 가상 데이터만 사용해요. 조직 내부 소스에서 파생한 시나리오·업무 문서·실제 계정·인증정보·운영 기록을 커밋하지 않아요.

## 개발 환경

Node.js 24와 저장소에 포함된 Yarn 4.18.0을 사용해요. 저장소 루트에서 다음 명령으로 화면 의존성을 설치하고 빌드할 수 있어요.

```sh
cd studio
node ../tools/yarn-4.18.0.cjs install --immutable
node --experimental-strip-types build.ts
```

화면 빌드 결과는 `web/studio/`에 생성돼요. 화면 빌드만으로 서버나 기기 실행 환경이 시작되지는 않아요. 전체 실행에는 PostgreSQL, 인증·실행기 설정과 테스트 대상에 맞는 브라우저 또는 기기 연결이 필요해요. 배포 설정은 [호스팅 설정 안내](docs/hosting.md)를 참고해 주세요.

화면 구조와 API 경로는 [Studio 안내](studio/README.md), UI 규격은 [디자인 기준](studio/DESIGN.md)에서 확인할 수 있어요.
