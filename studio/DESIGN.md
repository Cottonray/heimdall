# heimdall design

React + shadcn/ui 기반의 QA 워크스페이스. 현재 디자인의 정본은 이 문서, `src/components/ui`, `src/styles.css`이며 화면별 스타일 복사본을 만들지 않는다.

## 화면과 브랜드

- 브랜드는 소문자 `heimdall`. 사이드바와 로그인 헤더는 부엉이와 이름이 붙은 `HeimdallWordmark`를 사용한다. 표시 영역은 후속 요청으로 144×40px에서 128×36px로 줄였다. 파비콘은 글자 없는 부엉이 원본을 사용한다. 밝은 모드의 검정 글자는 `src/assets/heimdall-wordmark.png`, 다크 모드의 밝은 글자는 `src/assets/heimdall-wordmark-dark.png`이며 부엉이 블루는 유지한다. 글자 없는 부엉이 원본 `src/assets/heimdall.png`는 쇼룸·아이콘 용도로 보존한다.
- 라이트 테마는 흰 배경과 `#2667ad` JB 계열 블루, 다크 테마는 짙은 배경과 `#75ace2`를 사용한다. 실제 색상 값은 `src/styles.css`의 의미 토큰에서만 정의한다.
- 로그인 페이지 → 프로젝트 홈 → 프로젝트 워크스페이스 순서다. 프로젝트 홈의 사이드바에는 프로젝트·디바이스팜 메뉴와 테마를 둔다. 상단 작업 탭은 숨긴다. 프로젝트 목록을 표시하며 프로필은 공통 상단 헤더에 두며 클릭하면 설정·로그아웃 드롭다운을 연다. 화면 제목과 새 프로젝트·새로고침 등 페이지 작업은 헤더 아래 본문에 배치한다. 디바이스팜 및 프로젝트 내부 화면에도 같은 경계를 적용한다.
- 프로젝트를 선택하면 해당 프로젝트의 대시보드가 기본 화면이다. 프로젝트 내부에서는 프로젝트별 메뉴와 상단 작업 탭을 표시하되 프로젝트 목록 탭은 제외한다. 사이드바 상단에는 프로젝트 목록으로 돌아가기, 현재 프로젝트 이름과 프로젝트 설정 순서로 둔다. 홈으로 돌아오면 전체 범위를 새로 조회하고 열린 테스트 탭은 보존한다. 현재 통계는 API가 제공하는 최근 최대 60개 테스트 기준이며 누적 전체 통계나 코드 커버리지로 표시하지 않는다.
- 본문은 남은 화면 전체를 사용한다. 소개 배너, 실시간 연결 배지, 홈서버·샘플 금융 거래 문구, AI 쇼룸 링크, AI 사용 가능 문구는 추가하지 않는다.
- 사이드바 하단에는 테마를 둔다. 설정은 프로필 메뉴에서 연다. MCP 연결 정보는 설정 화면에서 제공한다.

## 공통 컴포넌트

공식 shadcn CLI/registry 컴포넌트를 기준으로 한다. 제품에 필요한 확장은 아래 공통 컴포넌트의 variant/size로 관리한다.

| 요소 | 정본 | 사용 규격 |
| --- | --- | --- |
| 페이지 제목 | `PageHeader` | 메뉴 화면의 제목·설명·액션을 공통으로 사용. 제목은 text-2xl, 액션은 제목 행 상단에 고정하여 설명 유무에 따라 높이가 움직이지 않음 |
| 플랫폼 로고 | `PlatformIcon` | 실제 기기의 Android 또는 iOS만 표시; [출처·라이선스](THIRD_PARTY_NOTICES.md) |
| 액션·메뉴·아이콘 | `Button` | `variant`와 `size`; 로고 홈 버튼은 `brand` 크기 |
| 프로젝트 카드 | `Item` | `variant="project" size="project" asChild` |
| 테스트 목록·최근 테스트 | `Item` | `variant="row" size="row" asChild` |
| 입력·검색·장문 | `Input`, `SearchInput`, `Textarea` | 검색 아이콘과 입력 여백은 `SearchInput` 내부에서 관리 |
| 폼 라벨 | `Label` | 기본 또는 `subtle` variant |
| 테마 전환 | `Select`, `ThemeControls` | 테두리·그림자 없는 `SelectTrigger variant="ghost"`; 사이드바에서 동일한 조작부 |
| 작업 탭 | `WorkspaceTab` | 제목과 닫기 버튼을 하나의 활성 배경·테두리로 묶고 중첩 버튼 없이 구성 |
| 프로필 | `Avatar`, `Badge`, `DropdownMenu`, `Input` | 관리자 역할만 Badge, 설정·로그아웃은 프로필 드롭다운 |
| 카드·상태·탭·대화상자 | `Card`, `Badge`, `Tabs`, `Dialog` | 공통 기본 간격과 의미 variant |
| 차트·로딩·구분선 | `Chart`, `Skeleton`, `Separator` | 의미 색상 및 레이아웃 속성 |
| 원격 화면 입력 | `PreviewSurface` | 좌표 보존을 위해 패딩·눌림 축소·disabled 투명도 없음 |

`Item asChild` 내부의 실제 `button`은 의미와 이벤트만 담당한다. 화면 코드에서 버튼 클래스, 기본 HTML 입력·대화상자, 별도 CSS를 작성하지 않는다. 외부 레이아웃은 정적 Tailwind 클래스로 지정하고 공통 컴포넌트의 색·모양·내부 여백은 사용부에서 덮어쓰지 않는다. 새로운 모양이 필요하면 공통 variant를 추가한다.

간격은 Tailwind 기본 스케일, 색은 `background/foreground`, `primary`, `muted`, `border/input/ring`, `success/destructive`, `sidebar` 토큰을 쓴다. 상태는 색뿐 아니라 텍스트로도 전달한다. 아이콘은 공통 `material-icons.tsx`의 Google Material Symbols Outlined SVG를 사용하고 입력에는 라벨, 아이콘 버튼에는 접근 가능한 이름을 제공한다. Radix가 Dialog/Tabs/Select의 키보드 및 포커스를 처리한다.

## 테마와 동작

- 하나의 `화면 테마` 드롭다운에서 `라이트 모드`, `다크 모드`, `시스템 설정 따르기`를 선택한다. 설정 모달에서는 테마를 중복 표시하지 않는다.
- `시스템 설정 따르기`를 선택하면 OS의 `prefers-color-scheme` 변경을 자동 반영한다. 다른 두 옵션은 표시 테마를 직접 지정한다.
- `heimdall.theme`에 `light`, `dark`, `system` 중 선택을 저장한다. 기존 선택은 보존하며 처음 사용할 때는 라이트다. 로그인 화면에도 선택이 적용된다.
- 공통 press 토큰으로 클릭 피드백을 제공하고 `prefers-reduced-motion`에서는 생략한다. 원격 화면 좌표 입력에는 축소 효과를 적용하지 않는다.
- 일반 화면 텍스트 선택과 WebKit 클릭 하이라이트, 이미지·링크의 기본 드래그 잔상은 표시하지 않는다. 입력·편집·코드·출력·증적은 선택/복사를 유지한다. 화면 전체의 기본 드래그를 차단한다. 보드 순서는 이동 버튼으로 바꾸며 드래그 핸들은 표시하지 않는다.
- 스크롤바는 숨기되 본문·사이드바·입력창·대화상자의 휠·터치·키보드 스크롤은 유지한다.

## 디바이스와 빈 상태

- 디바이스팜은 실제 목록만 표시한다. 유형은 `가상 기기`·`실물 기기`, 플랫폼은 Android·iOS로 구분하고 iOS 가상 기기에는 `시뮬레이터`를 쓴다. ID는 작은 보조 정보이며 `현재 테스트 기기` 배지는 표시하지 않는다.
- ADB 상태와 부팅 완료·서버 점유 상태를 확인한다. 준비된 기기는 `사용가능` 또는 `사용 중`, 준비 중인 기기는 `부팅 중`, 권한 미승인은 `승인 대기`, 끊긴 기기는 `오프라인`이다. 원격 제어 대상이 아닌 기기는 `연결 지원 대기`로 표시한다. 개별 상태나 전체 조회에 실패하면 기존 카드에도 `상태 확인 불가`를 표시하며 성공 조회 전까지 해제하지 않는다.
- 제목 아래 수량은 가상·실물 기기 수이며 사용자 접속 수로 표시하지 않는다. 조회 실패 때는 수량 대신 확인 불가 상태를 표시한다. 현재 iOS 기기가 없으므로 iOS 예시 카드를 추가하지 않는다.
- 사용자 요청으로 삭제한 41개 테스트 기록을 통계나 예시로 다시 채우지 않는다. 빈 프로젝트는 과거 보드 타일을 초기화하고 실제 빈 상태를 보여 준다.

## 자동 검사

`@shadcn/lint`의 6개 규칙을 모두 오류로 처리한다.

| 규칙 | 차단 대상 |
| --- | --- |
| `no-restyle` | 공통 컴포넌트의 색·모양·내부 간격 덮어쓰기 |
| `no-raw-colors` | 임의 팔레트·색상·SVG 색상 |
| `no-arbitrary-values` | `p-[13px]` 등의 임의 값 |
| `no-inline-styles` | 인라인 스타일과 style 태그 |
| `no-unknown-classes` | Tailwind가 생성할 수 없는 클래스 |
| `require-static-classes` | 검사할 수 없는 동적 컴포넌트 클래스 |

공통 UI 원본에만 restyle/arbitrary/static 예외가 있다. 색상·인라인 스타일 검사는 공통 UI에도 적용한다. 검색창의 `pl-9` 예외는 제거했으며 feature 영역에는 스타일 예외를 두지 않는다. ESLint 인라인 해제 주석으로 규칙을 우회할 수 없다.

`verify-design-lint.ts`는 각 규칙의 독립 위반 사례, 기본 HTML 컨트롤 우회, 공통 UI 예외 범위, 올바른 토큰·variant 사용을 검증한다. `yarn check`와 `../check.ts`는 strict TypeScript, ESLint, hooks·접근성, 디자인 규칙과 검출 검사, 기존 테스트를 통과해야 빌드를 생성한다. `../deploy.sh`도 이 검사를 배포 전에 실행한다.

공식 근거: [shadcn/ui CLI](https://ui.shadcn.com/docs/cli), [shadcn/lint 규칙](https://github.com/shadcn-ui/lint/blob/main/docs/rules.md).

- 팝업 오버레이는 두 테마 모두 `bg-black/50`을 사용한다. `foreground`는 다크 모드에서 밝은 글자색으로 바뀌므로 배경 차광에 사용하지 않는다.
- 사용자 이름·Avatar·관리자 역할 Badge는 하나의 프로필 Button 안에 둔다. 설정과 로그아웃은 프로필 드롭다운에 두며, 사이드바 설정 버튼은 표시하지 않는다. 설정 화면에서 프로필 이미지와 비밀번호를 변경한다. 이미지가 없거나 로딩에 실패하면 이름의 첫 글자(grapheme)와 사용자 ID에서 정한 고정 색상을 표시한다. 6색 팔레트는 styles.css에서 공통 관리하며 프로필 편집기에도 같은 글자·색상을 적용한다.

## 공통 데이터 테이블

`components/data-table.tsx`는 도메인 목록 등 구조화된 목록에 재사용한다. 공식 shadcn Table·Checkbox·Button·SearchInput·Select를 조합하고 기능 화면은 컬럼과 행 ID·표시 이름·검색 문자열을 전달한다. 도메인 테이블은 이름·주소 정렬과 관리자 전용 수정·삭제 열을 제공한다.

- 체크박스로 개별 행과 현재 페이지 전체를 선택한다. 일부만 선택하면 헤더 체크박스는 혼합 상태다.
- 선택은 검색·정렬·페이지 이동 중 유지하고 현재 데이터에 존재하는 행만 선택 수에 포함한다. 선택 해제는 전체 선택을 초기화한다.
- 검색 시 첫 페이지로 이동한다. 정렬은 오름차순·내림차순으로 전환한다.
- 페이지당 10·20·50개를 지원하며 빈 목록과 검색 결과 없음은 별도로 표시한다. 좁은 화면에서는 표 영역에서 가로 스크롤한다.
- 일반 사용자는 목록 검색·정렬·선택만 가능하며 관리자만 기존 권한 검사에 따라 도메인을 변경한다. 선택만으로 도메인을 수정하거나 삭제하지 않는다.

- 로딩 Skeleton은 공통 `bg-muted`를 사용하며 디바이스팜은 실제 카드와 같은 반응형 열 구조를 유지한다.
- 대시보드 제목 아래 최근 테스트 수 설명과 유형 커버리지 부제는 표시하지 않는다.

- 정렬 헤더 버튼은 컬럼 전체 영역을 차지하고 정렬 아이콘은 오른쪽에 배치한다. 컬럼 오른쪽 경계에서 포인터 드래그 또는 키보드 좌우 화살표로 너비를 조절하며 정렬과 리사이즈 동작은 분리한다. 너비 범위는 120–1200px이며 좁은 화면에서는 테이블 내부 가로 스크롤을 사용한다.

## 디바이스 원격 창

디바이스 탐색 카드는 공통 Item의 project variant로 전체 영역을 링크로 만든다. 카드 클릭 시 `?device=<serial>` 전용 원격 창을 열고 현재 로그인 세션을 사용한다. 원격 화면은 사이드바·작업 탭 대신 기기 이름, 연결·제어 상태, 화면과 조작 버튼을 표시한다. 로그인 화면을 거쳐도 요청한 기기 ID를 보존한다. 연결되지 않은 기기나 지원하지 않는 기기를 다른 기기로 대체하지 않는다.

원격 화면은 기기 영상을 받고 탭·스와이프·문자 입력·Android 이동 버튼을 제공한다. 제어권이 없거나 연결이 끊기면 입력을 막고 상태를 표시한다. 창을 닫거나 연결을 해제하면 스트림과 제어권을 정리한다.

## 디바이스 점유·웹 디버깅 (2026-10-08)
